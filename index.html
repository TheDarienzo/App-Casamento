                Os dados ficam na nuvem e neste aparelho. Exporte um arquivo de backup de vez em quando para guardar uma cópia de segurança de tudo.

                O app procura uma versão nova sempre que é aberto. Se você acabou de publicar uma atualização, pode buscar agora.
